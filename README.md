To use use this in Obsidian when you open obsidian for the first time select 'use folder as vault' and select the folder that has this files.

Then go to the config, go to `Files and links` and where it says 'Default location for new attachments' select the option In the folder specified below; then select files.

This will make that any image you paste while taking notes here will be saved in that folder.
