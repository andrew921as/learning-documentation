JavaScript crea objetos temporales que representan tipos primitivos para poder utilizar metodos y atributos de los mismos, a estos objetos propiedades se les conoce como Object wrappers. Esto tomando por ejemplo al metodo *.lenght()* de los String, este metodo no viene por si mismo con un String, viene con el objeto *new String()*, y es el motor de JS que se encarga de envolver el valor primitivo en ese objeto, pero este se elimina en el momento en que ya cumplio su cometido.
