Single-SPA is a JavaScript framework for front-end microservices. It helps combine multiple frameworks/applications into one seamless experience.

### Benefits:
- Independent deployment of each module
- Technology agnostic (You can use React, Vue, Angular, etc...)
- Easy code splitting and lazy loading
- Clear team ownership and separation
- Reuse of common components and assets
